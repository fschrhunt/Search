# Search assets

The lockup is the Search symbol and wordmark in one transparent SVG. The black
and white versions share the same geometry and differ only in fill color, so the
README can match GitHub's light or dark theme.

| Mark | Black | White | Use |
| --- | --- | --- | --- |
| Lockup | [SVG](black/lockup.svg) | [SVG](white/lockup.svg) | README and product pages |
| Logo | [SVG](black/logo.svg) | [SVG](white/logo.svg) | Compact brand mark |

The supplied black lockup uses `#111111`; the white variant uses `#d1d7e0` for
contrast in dark mode. The SVGs have transparent backgrounds and no font or
raster dependencies. Scale proportionally and leave clear space around the
mark.
